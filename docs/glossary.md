# Glossary

本文件记录 AI Quant Trading 中容易混淆的业务术语、技术术语和命名约定。

## 业务术语

- A 股：中国大陆股票市场标的。
- 自选股：用户关注的股票列表，常作为数据同步、行情订阅和机会池默认范围。
- 因子：用于预测、筛选或解释股票表现的特征，例如技术、基本面、资金流、情绪、宏观因子。
- Alpha：与市场基准无关的超额收益信号或研究模块。
- 回测：用历史数据验证策略表现。
- 模拟盘：不连接真实券商账户的纸面交易环境。
- 实盘：真实券商账户和真实下单链路，高风险。
- 条件单：条件触发后创建的模拟盘订单意图。
- 机会池：按信号、评分或规则筛出的候选股票列表。
- 风控：仓位、止损、集中度、回撤和权限等风险约束。
- 策略组合（Strategy Portfolio）：用户在一个市场中选定的一组策略、权重、风险否决规则和自选股成员。它是产生自动决策和报告的业务边界，不等同于真实持仓组合。
- 策略组合版本（Portfolio Version）：一次决策运行所使用的、不可修改的策略选择、权重、阈值和规则快照。修改组合配置会创建新版本，不能覆盖历史版本。
- 组合成员（Membership）：一只标的加入某个策略组合的关系；同一标的可以同时属于多个策略组合。
- 决策运行（Decision Run）：对一个策略组合、一个市场时点和一份冻结输入快照执行确定性评分的过程。
- 决策（Decision）：决策运行对一个组合成员给出的结构化动作、综合分、贡献、数据质量和原因码。它不是订单，也不构成投资建议。
- 决策动作（Decision Action）：`买入候选`、`关注`、`观望`、`减仓候选`、`重大风险` 五个互斥状态；前四个由综合分和滞回状态机决定，重大风险只由风险否决规则覆盖产生。
- 状态变化（State Change）：同一组合成员的已确认决策动作相对上一份有效决策发生改变。首次建立的普通状态不是状态变化；首次重大风险例外，必须通知。
- 风险否决（Risk Veto）：由用户配置的风险策略命中后，对综合分状态机的确定性覆盖。AI 不得创建、删除或改变风险否决结果。
- 输入快照（Decision Input Snapshot）：某次决策所读取的行情、指标、证据、数据质量、成员清单和版本引用的不可变记录，可用于复现。
- 决策报告（Decision Report）：由确定性决策投影出的不可变报告正文和附件清单。AI 解释作为独立、版本化的补充件关联到决策，不能重写报告动作。
- 通知目标（Notification Target）：一个可测试、可禁用、归属于当前 workspace 的消息接收端，例如企业微信机器人、PushPlus、飞书群机器人或 QQ 官方机器人。
- 通知路由（Notification Route）：策略组合、事件类型和一个或多个通知目标之间的配置关系。路由决定发送给谁，不改变决策。
- 投递尝试（Delivery Attempt）：向一个通知目标发送一份摘要或链接的一次不可变结果记录，包含幂等键、请求摘要、响应摘要、重试状态和时间。
- 自动推送资格（Auto-push Eligibility）：一个市场和策略组合被允许自动推送前必须同时满足数据预览、历史验证、当前数据健康和各通知目标测试成功的门槛。
- 市场适配器（Market Adapter）：明确一个市场的标的标识、时区、交易日历、公司行动、价格精度、K 线能力和数据质量语义的边界；不能把 A 股假设隐式套用到其他市场。
- 完成 K 线（Closed Bar）：已经结束且不会再被行情提供方修订的 K 线。盘中状态确认只能使用完成的 5 分钟 K 线。

## 技术术语

- Dashboard：FastAPI 同源托管的 Vue 3/TypeScript Web 工作台，提供决策、研究、报告、Agent、模拟盘和设置工作流。
- Qlib：历史兼容命名；当前部分运行时能力是轻量本地信号，不等同完整 pyqlib 训练栈。
- Signal Engine：运行时 AI 信号边界，详见 `docs/decisions/0001-signal-engine-v2.md`。
- AI Runtime：workspace 隔离的 provider、Agent 任务、结构化报告和研究补充件运行时；它只能解释和生成研究 artifact，不能改变确定性决策、风险或自动推送资格。
- Agentic：Agent 驱动的投研、策略实验、信号市场和模拟盘桥接领域层。
- DataHub：数据健康、覆盖率、决策矩阵和数据源状态相关页面/API。
- Watchlist：自选股。
- E2E：Playwright 浏览器端到端测试。

## 命名约定

- `qlib_*`：legacy 兼容字段，新增代码应确认是否应该使用 Signal Engine 语义。
- `signal_*`：新信号语义优先命名。
- `paper_*`：模拟盘相关。
- `ai_*`：AI Runtime 的任务、provider、报告和前端状态字段。
